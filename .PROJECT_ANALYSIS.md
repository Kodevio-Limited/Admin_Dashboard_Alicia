## 4. AUTHENTICATION FLOW

- **Library:** Better Auth (client-side via `better-auth/react`)
- **Backend URL:** `VITE_APP_SERVER` env variable (defaults to `http://localhost:5000`)
- **API Prefix:** `/api/v1`
- **Credentials:** Included via `credentials: 'include'` for cookie-based auth
- **Sign-in Flow:**
    1. User submits email + password via TanStack Form (Zod validated)
    2. `auth.signIn.email()` is called
    3. On success, checks `user.emailVerified` — redirects to `/verification` if not verified
    4. Checks `user.role` — only `admin` / `superadmin` allowed; others get signed out with error toast
    5. On success, navigates to `/` (Dashboard)

## 11. NOTES / OBSERVATIONS

1. **Mock Data Layer:** All CRUD operations mutate in-memory arrays. Data resets on page refresh. Ready for backend integration via the existing `request()` API client.

2. **TanStack Query Installed But Unused:** `@tanstack/react-query` is installed (and devtools) but no queries/hooks are defined. This is the next logical step for connecting to a real API.

3. **i18n Coverage:** Only English (`en`) has been fully populated. German (`de`) and Dutch (`nl`) translation files exist but need content. The sidebar labels use a `t()` function with fallback to English keys.

4. **Form System:** Custom `useAppForm` hook with field components is well-architected. All routes should use it for consistency.

5. **Auth Guards:** The main layout doesn't currently have explicit auth guards — the sign-in logic redirects unauthorized users but route protection isn't enforced at the router level.

6. **Image Handling:** `resolveImage()` utility handles various image URL formats. Upload API is structured but may need backend endpoint.

7. **Responsiveness:** Inbox has explicit responsive behavior (mobile/desktop). Other pages use standard Tailwind responsive grid utilities.

8. **SEO:** `index.html` has basic meta tags. `public/robots.txt` and `manifest.json` are present.

9. **Build Output:** Configured for Vercel SPA deployment with `vercel.json` rewrites.

10. **TypeScript Strict Mode:** Enabled with `noUnusedLocals`, `noUnusedParameters`, `noFallthroughCasesInSwitch`, `verbatimModuleSyntax`.
